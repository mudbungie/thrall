The founding installed the ast-grep rules a dependency-free, spawn-free, lock-free skeleton can actually be measured against. Four house rules had nothing to bite on yet and were deliberately left out rather than installed vacuous. Each lands with the surface it governs.

- **`unsafe` confined to one file** (house rule 3). Its location list is the one authority — a site is added to the confined file, never the list widened. thrall has no `unsafe` today; the executor's child-termination cascade may want some.
- **`Mutex`/`RwLock` confined to a lock chokepoint** (rule 7, first half). thrall holds no cross-thread state today. When the loop does, the chokepoint is one file and the carve-outs are named with their measured reason, never assumed.
- **No bare `Command::new`, no bare fork.** Every child goes through one spawn boundary. Two distinct reasons, both learned the expensive way upstream: a child that inherits a parent's ambient git environment forks its own git against the wrong repository, and a fork on any thread copies a peer's open write fd into a child that holds it until its own exec — so a test that writes a fixture script and execs it races to ETXTBSY. The victim's own care cannot save it, because the fork is the other party: the discipline belongs at the fork, not at the write.
- **`no-rc-refcell`** already landed; it is the half of rule 7 that needs no chokepoint to exist.

Deliverable: the rules, their fixtures, and the `rules-audit` negative check extended to cover them — the tree clean AND the fixtures still flagged, so a silently-broken rule cannot pass as green forever.
