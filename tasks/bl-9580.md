Same defect as yog bl-d147 and yog-android bl-b55d: Config::merge in tarpaulin 0.35.2 never copies the engine from the command line when a toml exists, so --engine llvm on the Makefile line is dead and every run is ptrace, whose line attribution depends on thread timing — the two boxes disagree on one line and the runner loses. Surfaced by ops bl-fb2c's end-to-end proof on this repo (the advisories workflow dispatched ci.yml on a branch and ci.yml failed at coverage, exactly as release-plz.yml has on main since the rustls bump). The llvm engine counts more lines (~9% on yog-android), so cover what it sees.
