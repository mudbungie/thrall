Operator ruling 2026-08-30 named the registry — `ghcr.io/mudbungie/<component>`,
one package per repo, pushed only from that repo's release workflow at tag
time, immutable version and digest tags, never a moving `latest` — **on the
condition that no image ships a secret, mechanically.** yog `docs/DESIGN.md`
§10.1 carries the ruling and states the required property; this is thrall's
half of it.

Nothing standing covers the condition. `make leak-scan` reads the git INDEX. An
image is built from inputs no commit has: the build context as the engine
receives it, the base layers, the package index, and the image CONFIG. The
`Cargo.toml` publish guard is the analogue one channel over — and the build
context is the image's version of it.

The stake is higher here than for the other components. A foot holds
operator-issued leaf material and a config of argv commands; the Containerfile
says in as many words that a certificate baked into a layer is a certificate
published to everyone who can pull it. That sentence has never been checked by
anything.

Deliver `make image-scan`, wired so `make image` runs it, over three surfaces:

- **The authored filesystem.** What the build added above the pinned base
  digest, isolated by content-addressed comparison against the base rather
  than by trusting the `COPY` line. The distro floor (`apk add
  ca-certificates`) is ACCOUNTED FOR rather than exempted: apk's own ownership
  ledger says which files a package put there, and everything else above the
  base is this repo's and is scanned.
- **The image config.** Every `Env`, `Label` and history entry — build
  arguments echo into history, and an `ENV` ships to everyone who pulls.
- **The same rule table**, `scripts/leak-rules.sh`, sourced and never copied.

Posture carried over from the source gate unchanged: findings LOCATE and never
reprint; unreadable is rejected rather than skipped, with the expected binary
set DERIVED from the Containerfile's `COPY --from=` destination rather than
typed; both directions, so a self-test plants a fabricated secret in a layer
AND in an `ENV` and proves each is caught, while the real image passes clean.

Shell and Makefile are the medium. No new Rust surface, so the coverage floor
and the confinement rules are untouched. bash 3.2, like the rest of the
scripts here — no associative arrays.
