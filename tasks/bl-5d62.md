Round-1 install lane of the suite usability campaign (yog docs/STORIES.md S0/S9).

## Scenario step

Enrol the local foot on a single-box install: mint a foot leaf on the engine,
place it in `<thrall-data>/wire/workspaces/home/`, write `tools.json`, run the
foot. Engine is yog main tip (PROTOCOL 13); foot is this repo's main tip
(PROTOCOL 8, which is bl-f88f).

## Gesture

    thrall run

## Verbatim stderr

    home: wire protocol mismatch: this foot speaks version 8, the engine speaks 13. There is no negotiation — upgrade the older component until both speak one version.. Dialling this engine again in 1s.
    home: … again in 2s.
    home: … again in 4s.
    home: … again in 8s.
    home: … again in 16s.
    home: … again in 32s.

and on, forever, settling at the one-minute cap. The process never exits.

## Expected

The channel ends, naming the two versions. The README already draws the line
this sits on the wrong side of:

> Two refusals are told apart and never collapsed: the engine declining this
> box's *read* is its own predecessor's connection still dying, which frees
> within one hold's width and is waited past; the engine declining what this
> box *offers* is another connection serving under its name, and that ends the
> channel.

A version preface mismatch is a third class and belongs with the second: it is
a property of the two binaries, it cannot change while either process lives,
and the message itself says so — *"There is no negotiation — upgrade the older
component"*. Redialling a fact that only a new binary can change is a busy loop
that writes a line a minute into the operator's journal forever.

The same argument the README makes about restart policy applies: *"a foot that
cannot be a foot at all exits and says why"*. This foot cannot be a foot at all.

## Also, cosmetically

The line reads `…one version.. Dialling this engine again in 1s.` — two periods.
The refusal string already ends in `.` and the redial suffix appends another.

## Severity

p2. It is downstream of bl-f88f (the pin itself), but it is separable and will
outlive it: the next protocol bump reproduces it exactly, and this is the class
of failure a foot meets most often in the field — an engine upgraded ahead of
its feet.
