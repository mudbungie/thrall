thrall ships `make install` and nothing else. There is no `scripts/deploy/`, no
service unit and no reconciler, so the foot on a box is whatever somebody
started in a terminal — and it stops at the next logout, never restarts after a
crash, and never picks up a release.

Observed on a live box: the data root was provisioned by hand (a `tools.json`
and two channel directories under `wire/workspaces/`), the engine on the other
end of one of those channels had issued this box a foot certificate, and NO
thrall process was running at all. The engine therefore had no live foot and
could execute nothing, with nothing anywhere saying so. The installed binary
was 0.0.2 while 0.0.5 was published.

Operator ruling 2026-09-05: every device should run effectively full CD — any
new publication should result in an upgrade of the running versions.

Add the deployment, in the shape yog and lernie already hold:

  * `scripts/deploy/thrall.service` — a user unit, `ExecStart=%h/.local/bin/thrall run`,
    `Restart=always` with a StartLimit. `thrall run` does not return while a
    channel is up and exits naming a channel it cannot be a foot for, so
    supervision is the restart, which is what the README already says belongs
    to this machine.
  * `scripts/deploy/reconcile.sh` — the newest live version off the crates.io
    sparse index (yank-filtered, so a yank is the rollback lever), `cargo
    install --root $HOME/.local --locked --version <v> --force`, then restart
    the unit only when this box is not executing anything.

    The idle read is the unit cgroup process count, and for a NATIVE unit that
    is honest: thrall runs every tool as a child process (`src/spawn.rs`), so an
    idle foot is exactly one process in its own cgroup and an invocation in
    flight is a child beside it. That is the same predicate the retired yog
    reconciler used, and the objection that retired it — a container unit whose
    cgroup holds a client process rather than the engine — does not reach a
    native unit.
  * `scripts/deploy/local.sh` + `make deploy-local` — seat it on this box, no
    ssh, enable lingering, end by running the reconciler once synchronously.
  * a self-test in the gate, both directions, driving the real script under
    fake `curl`/`cargo`/`systemctl`.
