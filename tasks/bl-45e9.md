The dial ladder (DESIGN 3.11, bl-bc2c) moves to the next endpoint only when the TCP connect fails. A socket that opens but is not the server — a private address answered by a stranger, a captive network — fails the handshake and ends the dial, with the rest of the list untried.

Make a rung the connect AND the mTLS handshake, as the desktop seat does (lernie bl-2723): an endpoint is passed over when its socket will not open or its handshake does not verify; each is bounded at about five seconds; the endpoint that worked is still kept in RAM for the run. Nothing of the gesture has crossed when a handshake fails, so falling through repeats nothing.

Amend DESIGN 3.11, which currently states the opposite ('a rung is the connect and not the handshake').
