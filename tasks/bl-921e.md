## What is broken

thrall's `src/dht` (landed in bl-0a8b) was mirrored from yog's DHT client before yog measured it against the live mainline. yog then fixed four live defects, each measured from its deployed engine box (yog REMOTE §13.7 ruling 3 carries the tables):

- yog bl-f6e1: BEP 44 get/put asked the bootstrap routers, which answer `find_node` and never `get` — the walk was dark in one round.
- yog bl-9408 / bl-d00f: walks ended dark — the one answering router names one node eight times; silent, refusing and unreachable nodes kept frontier slots; the bootstrap was never re-asked when the frontier ran dry; a `204 unknown query` to `get` counted as a reply.
- yog bl-d9c1: lockstep rounds replaced by a sliding window — up to alpha in the air, each with its own deadline, the next node asked the moment any answers or times out; `put` sends to every token holder at once. Defaults alpha=8, K=8, deadline 1 s, max_queries 64; `Config.round` renamed `deadline`.

Live after all four: lookup median ~6.5 s, put ~7.5 s, get ~7.5 s.

thrall still has all of them, plus a 2 s round default and a two-router bootstrap list (yog now names four).

The test commons becomes a router door plus a holder, as the live mainline is. DESIGN amended where the walk is described.
