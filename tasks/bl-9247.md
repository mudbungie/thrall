ops bl-fb2c; lernie bl-9c29 is the same change with the full reasoning. An advisory is a fact about the day, not the tree: a gate that judges trees must not fail on it. make deny becomes cargo deny check bans licenses sources; make advisories is the check and make mend-advisories bumps every advised crate (cargo update -p, names read off cargo-deny's JSON diagnostics) and re-checks. .github/workflows/advisories.yml runs daily and on dispatch: check, mend, commit the lockfile on a branch, dispatch ci.yml on that branch, fast-forward main on a pass, delete the branch, dispatch release-plz.yml where no PAT pushes. A day main moved underneath the push fails and the next day's run begins again; an advisory with no fixed version fails the run, the one case that is a hand's.
